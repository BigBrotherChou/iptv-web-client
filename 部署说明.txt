IPTV 网页客户端 · iStoreOS 部署说明（Docker + nginx 方案）
====================================================================

【架构说明】
  局域网任意设备浏览器 → http://192.168.100.1:8088/
    ├─ 页面/解码库文件 ← 由 nginx 容器提供（静态文件）
    ├─ 频道清单 /iptv.m3u ← nginx 反代 uhttpd(:80)
    └─ 直播流 /udp/239.x.x.x:port ← nginx 反代 udpxy(:4022)
  解码全部发生在终端浏览器（MPEG-TS 拆包 → H.264 硬/软解），
  软路由只转发字节流，零解码负担，和机顶盒点播占用类似。

【部署包内容】（拆分版：首屏仅 92KB，解码库按需懒加载）
  html/index.html            页面结构（6.6KB）
  html/css/main.css          样式（18KB）
  html/js/app.js             业务逻辑（67KB，升级只传它）
  html/js/vendor/mpegts.min.js      TS 解码库（服务器已设一年缓存+gzip，传输约 63KB）
  html/js/vendor/hls.light.min.js   HLS 解码库（同上）
  nginx.conf                 nginx 容器配置（8088，host 网络，含 gzip 与缓存策略）

【一、上传文件到软路由】
  在 Windows 电脑上打开 PowerShell，执行（按提示输入路由器 root 密码）：

    ssh root@192.168.100.1 "mkdir -p /root/iptv-web"
    scp -r "C:\Users\zhouy\Desktop\iptv_demo\软路由部署包\html" root@192.168.100.1:/root/iptv-web/
    scp "C:\Users\zhouy\Desktop\iptv_demo\软路由部署包\nginx.conf" root@192.168.100.1:/root/iptv-web/

【二、启动容器】（iStoreOS 已装 Docker 的前提）

    docker run -d --name iptv-web --restart always \
      --network host \
      -v /root/iptv-web/html:/usr/share/nginx/html:ro \
      -v /root/iptv-web/nginx.conf:/etc/nginx/conf.d/default.conf:ro \
      nginx:alpine

  说明：--network host 让容器直接使用路由器网络，
  8088 端口不会被 uhttpd/quickstart 占用（它们在 80）。
  若 nginx:alpine 拉取慢，可换 docker.1ms.run/nginx:alpine 镜像源。

【三、验证】
  1. 路由器上：curl -s http://127.0.0.1:8088/ | head -c 200   （应看到 HTML）
  2. 电脑/手机浏览器打开 http://192.168.100.1:8088/
     应自动列出 62 个频道，点击即播。
  3. 若播放失败先检查：curl -s -o /dev/null -w "%{http_code}" \
     "http://127.0.0.1:8088/udp/239.49.8.74:8000"  （应返回 200）

【日常使用】
  · 手机/平板/电脑连家里 WiFi，浏览器收藏 http://192.168.100.1:8088/
  · 页面每台设备各自维护画面缩略图（localStorage）
  · 后台预览默认 90 秒/台低频轮换；清单变化后重新打开页面会自动同步

【常见问题】
  · nginx.conf 里流反代写的是 http://192.168.100.1:4022 而非 127.0.0.1:4022：
    这是因为本机 udpxy 以 -a 192.168.100.1 启动、只监听 LAN IP。
    若日后更换路由器 IP 或 udpxy 改为监听 0.0.0.0，同步改这一行即可。
  · 某台长期标「预览受限/拉流失败」：
    多半是 udpxy 并发上限（标准版 3 个客户端）被家里设备占满，
    断开一路即恢复；个别台加密/失效则始终拉不到，属正常。
  · iPhone Safari：iOS 不支持网页直接解 TS 流（MSE 受限），
    iPhone 上建议用支持组播源的播放器 App 或安卓/电脑浏览器观看；
    Windows/Mac/安卓 Chrome/Edge 均正常。
  · 更新页面版本：重新 scp 覆盖 html/index.html、html/css/main.css、html/js/app.js
    （三个小文件合计不到 92KB，浏览器下次打开即生效；vendor 库不动、无需重传）。
  · nginx 已开 gzip + 分级缓存：js/vendor/ 一年强缓存（首次加载后不再重传），
    页面/业务文件 no-cache（升级立即生效）。
  · 卸载：docker rm -f iptv-web && rm -rf /root/iptv-web

【端口调整】
  想换端口（如 9000）：改 nginx.conf 里的 listen 9000，
  docker restart iptv-web 即可，页面无需任何改动（自动适配地址）。
